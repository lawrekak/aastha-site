# Read first: how the GEO skills apply to this website

These skills come from zubair-trabzada/geo-seo-claude (MIT licence, commit ea29bd2, vendored 4 Oct 2026; see LICENSE). They were written for businesses that may advertise. This website belongs to an advocate in India, so the rules below **override anything in the GEO skills, agents or report templates**.

## Bar Council of India Rule 36

Advocates may not solicit work or advertise, directly or indirectly. So:

- **No promotional or comparative wording.** No "best", "top", "leading", "expert", "specialist", "trusted", "affordable", "free consultation", in any language. `node scripts/validate.mjs` enforces this, and it must pass.
- **No calls to action.** No "contact us", "book", "call now", WhatsApp buttons, lead forms, pricing or fees.
- **No results, clients, testimonials, ratings or review widgets.** Never suggest asking clients for reviews, adding Review or AggregateRating schema, or showing star ratings.
- **No outreach or placements.** No posting, commenting or answering on Reddit, Quora, YouTube or forums to build "brand mentions". No link building or paid listings. No Justdial, Sulekha, Quikr, Grotal or lawyer-lead portals. Don't create a Wikipedia or Wikidata entry about her.

  Brand-mention scans are **audit only**: report what exists, change nothing outside this repository.
- **Factual sameAs only.** Only verified profiles listed as `live` in `content/citations.json`.

## Decisions already made on this site

- Don't add explanatory legal text, FAQs or "documents usually relevant" back to the practice-area pages. The owner removed them in September 2026. Citable answers belong in the **blog** (`content/blog/`, skill `daily-law-blog`) and the guides.

  A low citability score on a practice page is expected: report it, don't "fix" it.
- Content lives in `content/*.json` and `content/blog/*.json`; templates are in `build.mjs`. Make changes in those files, never in `dist/`.
- AI crawlers are already allowed in `robots.txt`. `llms.txt` and `llms-full.txt` are generated by `build.mjs`.

## Excluded parts of the original repository

The following were not copied and must not be suggested:
- `geo-prospect`, `geo-proposal`, `geo-report-pdf`, the CRM web app and white-label templates (agency sales tools);
- `geo-update` (self-updater). To update, re-vendor deliberately.

## Running the scripts

```bash
python3 -m pip install -r .claude/skills/geo/requirements.txt
python3 .claude/skills/geo/scripts/fetch_page.py <url> page
python3 .claude/skills/geo/scripts/citability_scorer.py <url>
python3 .claude/skills/geo/scripts/llmstxt_generator.py <site-url>
```

Every change goes through a pull request and `node build.mjs && node scripts/validate.mjs`.
