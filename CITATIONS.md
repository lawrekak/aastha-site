# Listings and citations — done by hand, never automated

Links and listings for an advocate should come from factual directories, not link building. Automated link building breaks Google's spam policies and can look like solicitation under Rule 36. Use exactly these details everywhere:

```
Name:     Aastha Vishwakarma, Advocate
Office:   Vishwakarma, Kumar & Jain Law Offices
Address:  B-8, Vaishali Colony, Bhotia Parao, Haldwani, Uttarakhand 263139
Phone:    +91 88020 29468
Email:    aastha.vishi@gmail.com
Website:  https://advaasthavishwakarma.in
```

| Listing | What to do | Status |
|---|---|---|
| Google Business Profile | Claim "Vishwakarma, Kumar & Jain Law Offices", add the website, phone, email, category "Lawyer" and hours. Do not ask clients for reviews. | ☐ |
| Bing Places | Import from the Google Business Profile | ☐ |
| Bar Council of Uttarakhand / Bar Association | Check the enrolment record shows the current address and phone | ☐ |
| Justdial | Update the existing Vaishali Colony listing so it matches exactly | ☐ |
| Sulekha, LawRato | Update or claim listings so they match; turn off paid "lead" features | ☐ |
| LinkedIn | Add the website to her profile | ☐ |
| Articles | Any articles she writes for law portals or local papers may carry an author line with the website | ☐ |

Do not buy links, join link exchanges or pay for "top lawyer" placements.
